# Reflection Questions

# .1. How did you approach creating more flexible functions with parameters?
My approach was similar to what I use in Python. I looked at the values that change in each case and turned them into parameters with default values so the function can handle different inputs without having to rewrite it.

# .2. What challenges did you face while incorporating conditional logic in your functions?
The only challenge I had was handling edge cases with undefined or invalid variables—for example, knowing when to use `isNaN()`, or catching when someone enters a string or a letter instead of a number. Since we haven't covered all the possible wrong inputs a user might enter to break the code in class yet, it wasn't always clear which invalid cases to check for.

# .3 How does refactoring improve the readability and maintainability of your code?
Refactoring makes things easier because instead of copying and pasting the same code over and over, you keep everything in one place. It is much simpler to read and easier to update later without breaking other parts of the file.
